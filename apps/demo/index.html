API

A deliberately small CSS custom-property API. No JavaScript state API is required.

--meter-css-track

Track background color.

--meter-css-optimum

Color for the native optimum state.

--meter-css-suboptimum

Color for the native sub-optimum state.

--meter-css-sub-suboptimum

Color for the native least-good state.
